# Documentation artwork

`brand.svg` and `demo-art.svg` are original vector artwork created for Banana Studio's documentation and covered by the repository's MIT license.

`workspace.jpg` and `area-edit.jpg` are captures of the actual application interface using an isolated, temporary local workspace with that original sample artwork and color variations. The sample cards were seeded for demonstration, not produced by an AI model. They contain no personal photographs, user generations, private workspace data or real API keys. No paid provider was called to make the screenshots.

TR: SVG dosyaları bu rehber için hazırlanmış özgün çizimlerdir. JPEG'ler gerçek uygulamanın, yalnızca bu örnek çizimleri içeren geçici ve ayrı bir yerel alanla alınmış ekran görüntüleridir. Örnek kartlar yapay zekâ çıktısı değildir. Kişisel fotoğraf, kullanıcı üretimi, özel çalışma alanı verisi veya gerçek API anahtarı içermez. Ekran görüntüleri için ücretli sağlayıcı çağrısı yapılmamıştır.
